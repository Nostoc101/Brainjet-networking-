# BrainJet - Facebook Virality Engine

BrainJet is an autonomous interface that turns raw ideas into viral Facebook content blueprints and detailed prompts for image/video generative AIs.

## 🛠️ Step-by-Step Setup

### Local Installation
Open your computer's terminal or command prompt inside the project folder and run:
```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

## 🚀 Pushing to GitHub
1. Create a repository on GitHub named `brainjet`.
2. Push your files using the command line:
```bash
git init
git add .
git commit -m "Initial commit of BrainJet Engine"
git branch -M main
git remote add origin https://github.com
git push -u origin main
```
## 🌐 Hosting Live
Once it's on GitHub, go to [Streamlit Community Cloud](https://streamlit.io "Streamlit Cloud Portal"), connect your repository, and deploy it completely for free so you can access your bot from your phone or any browser.
